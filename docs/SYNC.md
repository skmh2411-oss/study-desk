# 端末間同期の設定（任意）

未設定でも基本機能は端末内で使えます。このアプリはAPIへ自動課金される仕組みを持ちません。

1. Supabaseで個人用の **Free** プロジェクトを新規作成します。有料プランへ変更する必要はありません。
2. SQL Editorで同梱の `supabase.sql` を実行します。新しいプロジェクトで実施してください。再実行時に既存ポリシーがある場合は重複作成エラーになるため、削除せず既存定義を確認します。
3. Authentication → ProvidersでEmailを有効にします。AuthenticationのSite URLを公開したアプリのHTTPS URLに設定します。ユーザー登録はこのアプリの「新規登録」で1名だけ行い、確認メールを開いた後、アプリからログインします。登録後は管理画面で新規ユーザーの登録を無効化することを推奨します。
4. SupabaseのConnect/API設定にあるProject URLと **publishable key** または **anon key** をコピーします。service_role・secret keyは使用禁止です。
5. アプリの「設定とデータ → 同期」で入力し「接続設定を保存」。この操作は設定を端末へ保存するだけです。
6. メールアドレス・パスワードを入力して「ログイン」。次に「今すぐ同期」を押すと学習データを送受信します。
7. iPhoneとPCで同じURL・公開鍵・本人アカウントを設定します。初回はデータのある端末で同期してから、空の端末で同期してください。
8. 「再接続時の自動同期」を選ぶと、オフラインからオンラインへ戻った際に送受信します。通常の保存ごとに即時送信する仕組みではありません。端末を切り替える際は「今すぐ同期」を押してください。

## 安全性と競合

- サーバーは認証済み本人のデータだけを返します。RLSを有効化し、テーブルへの直接操作権限を除去しています。所有者を確認するSQL関数でのみアクセスします。
- 同期はレコードごとの版番号を比較してから更新します。端末内の更新とクラウドの更新が競合すると、自動的には採用せず、両方の内容を表示します。
- 採用する版を確認して選択すると、両方を解決履歴として端末に保存します。履歴JSONは「解決済み競合履歴を保存」からダウンロードできます。学習時間の二重計上を防ぐため、もう一方の版は通常の学習データとして複製しません。
- 競合発生後にさらに編集した場合は「今すぐ同期」を実行してから内容を再確認してください。
- 別のアカウント・別プロジェクトへの切り替えはデータ混在を避けるため拒否します。別ブラウザプロファイルを使用し、必要なデータだけバックアップから追加してください。
- 計測中のタイマー・表示設定・接続設定は同期しません。タイマーを終了して保存した記録は同期します。
- ログアウトしてもローカルデータは削除しません。共用端末にはインストールしないでください。
- Supabase公開鍵は秘密鍵ではありません。学習データを保護するのは認証とサーバーの所有者確認です。

## 無料枠と未検証範囲

2026年11月27日確認：Supabase Freeのデータベースは500MB、低稼働状態が7日間続くとプロジェクトが一時停止する場合があります。停止時はSupabase管理画面で再開してください。端末内の基本機能は継続できます。無料枠の条件は将来変更され得ます。

公式料金： https://supabase.com/pricing
公式RLS： https://supabase.com/docs/guides/database/postgres/row-level-security
公式CAS関数の制約：本SQLは本人の変更・カーソル読取りを直列化し、同じユーザーの未コミット更新を飛ばさず差分取得します。大量データのページ分割は初期版にはありません。同期する各レコードは2MB以下です。超えたレコードは端末内に保持したまま同期エラーを表示します。

実際のSupabaseプロジェクトは未作成・未接続です。SQLの実行、メール認証、実端末間同期、ネットワーク障害・RLSの実環境検証は、設定後に必要です。接続済みとして扱わないでください。

## v1.1から必要な通信先の承認

CSPで外部通信を制限しています。標準のdistは端末内保存専用です。同期を有効にする版では、ビルド前に `VITE_SUPABASE_ORIGIN=https://自分のプロジェクトID.supabase.co` を.env.localへ指定してください。GitHub Actionsを使う場合はリポジトリ変数 `STUDY_SUPABASE_ORIGIN` に同じ値を設定します。

再ビルド・更新後、設定画面に表示される承認済みURLと同じ接続先を登録します。公開用キーを入力しても、別プロジェクトへの通信は拒否します。URLの指定は通信先を許可するだけで、本人認証・SQL/RLSの代わりにはなりません。詳しくは[プライバシー・セキュリティ改善](PRIVACY_SECURITY.md)を参照してください。
