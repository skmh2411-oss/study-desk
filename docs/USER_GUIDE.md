# Study Desk の使い方

## PCで起動

Node.js 22.12以上（または24）を用意し、このフォルダーで次を実行します。

```sh
npm ci
npm run dev
```

Windowsでは `START_WINDOWS.cmd` をダブルクリックして起動することもできます（初回のNode.js導入は必要）。表示されたローカルURLをPCのブラウザで開きます。開発サーバーはホーム画面追加・オフライン利用の検証対象ではありません。

本番ビルドは `npm run build`。`dist` 内が公開用の静的ファイルです。ファイルを直接ダブルクリックせずHTTPサーバーまたはHTTPSのホスティングで配信します。

## GitHub Pagesへ公開

この段階の公開はユーザー操作です。未公開・未認証のサービスを接続済みとは扱いません。

1. GitHubで新規リポジトリを作成します。ソースコードだけを配置し、学習記録JSON・CSVやSupabaseの秘密鍵を含めないでください。
2. GitHub PagesはGitHub Freeの場合、公開リポジトリで利用できます。ソースコードは公開されますが、学習内容はアプリ内のブラウザ保存でありリポジトリに入りません。ソースの公開も避けたい場合はGitHubのプラン条件や別の無料静的ホスティングを確認してください。
3. Settings → Pages → Build and deployment → SourceをGitHub Actionsにします。
4. Actions → Deploy Study Desk to GitHub Pages → Run workflowを手動実行します。自動テストとビルド後、公開します。
5. 実行結果のURLをSafariで開きます。アプリのコードを公開する前に、リポジトリに個人データがないことを確認してください。

公式条件： https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages
公開容量・通信等の制限： https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## iPhone

SafariでHTTPS URLを開き、一度読み込みを完了してください。「共有 → ホーム画面に追加 → 追加」でアプリとして使えます。初回取得後、機内モードにして再度起動し、保存した内容が開けることを確認してください。

iPhone実機のバックグラウンド動作・ホーム画面追加は開発環境では未検証です。タイマーは音を鳴らすバックグラウンド処理ではなく、保存した時刻の差から復元します。画面ロック中の通知や終了中のアラームはありません。

## 最初の学習

1. 学習対象と科目・単元を登録します。試験日と目標時間を入力します。
2. 計測画面で対象と方法を選び開始。終了時に記録を保存します。忘れて長時間になった計測は保存前に確認します。
3. 計画画面で曜日ごとの時間・学習できない日を設定し、配分案をプレビューして反映します。
4. ノートはMarkdown、暗記は4段階評価で復習します。問題演習の正答率と学習時間は別々の指標です。
5. ChatGPTへの相談は設定画面で依頼文を作成します。実際に送る前に内容を確認し、返答のJSONを検証・プレビューして追加します。

## バックアップ・復元

「設定とデータ → バックアップ → JSONを保存」で全学習データをダウンロードします。週1回と更新前を目安に保存してください。ファイルには個人的なノートが含まれるため、本人だけが開ける場所で保管します。

復元はJSONを選択（または貼付）し「検証・プレビュー → 確認したデータを追加」。既存データと同じIDや重複は追加しません。既存の異なる内容を無断で上書きしません。初期版の復元は追加入力です。データを完全な過去状態へ巻き戻す機能ではありません。

削除したデータはゴミ箱から復元できます。完全削除ボタンはありません。Safariのサイトデータ消去、端末故障、ブラウザによる容量整理から守るにはバックアップが必要です。

## 更新・修正

ソースを修正したら `npm test` と `npm run build` を実行し、GitHubへ反映後、同じActionsを手動実行します。更新前にバックアップしてください。アプリの更新案内がある場合は計測を停止・保存してから適用します。保存データのスキーマを変えるときは `src/db.ts` のDexieバージョンとマイグレーションを追加し、既存DBの消去で対処しないでください。

同期は任意です。設定は `docs/SYNC.md` を参照してください。

計測中の状態は端末に残り、移動用JSONバックアップ・クラウド同期には含めません。端末を切り替える前に終了・保存してください。カウントダウンは設定時間を上限に記録し、ポモドーロの次の集中・休憩は手動開始します。

## v1.1のChatGPT共有

「設定 → ChatGPT」で共有する項目にチェックしてください。初期状態では0件です。対象・科目・単元・種類・検索で絞れます。本文・解答を含む実際の共有内容をプレビューし、「依頼文を作成 → 内容確認 → コピー」の順に操作します。対象条件や内容を変えた場合は依頼文を作り直してください。学習記録のメモ・誤答原因は追加の許可をしたときのみ含みます。

v1.1では外部通信先を制限しました。同期を使う場合は、ビルド前の承認済みProject URL指定が必要です。手順はdocs/PRIVACY_SECURITY.mdとdocs/SYNC.mdを参照してください。初期状態のまま端末内の基本機能を利用できます。
