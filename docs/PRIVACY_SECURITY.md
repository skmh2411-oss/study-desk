# v1.1 プライバシー・セキュリティ改善

## ChatGPTへ共有するデータ

設定 → ChatGPTで学習対象・科目・単元・種類・検索で絞り、個別チェックまたは「表示中のN件を選択」で指定します。初期状態は0件。絞り込みを変えると選択を解除します。「今回共有するデータを確認」で実際のJSONを表示します。

選択したノート本文、カード/問題の問題文・解答・補足、必要な所属IDなどは依頼文に含みます。正確な計測区間、復習全履歴、作成/更新日時、同期・認証情報は含めません。学習記録の自由メモと誤答原因は別チェックで許可したときのみ含めます。親や関連カードは自動追加しません。

「依頼文を作成」後、内容確認にチェックした場合のみコピー可能。選択条件、依頼、追加条件、選択データが変わった場合は古い依頼文のコピーを無効化し、作成し直します。プレビュー本文を手修正した場合は再確認が必要です。コピーを押すまでクリップボードへも書き込みません。自動送信・有料APIはありません。

選んだ文章に含まれる氏名や秘密情報の自動判定・匿名化はありません。表示された内容を確認してください。画面を閉じて再度開くと共有選択は0件に戻り、送信設定を端末に恒久保存しません。

## CSP

本番ビルドではHTMLのhead先頭へmeta CSPを挿入します。GitHub PagesでもHTMLに同梱した設定が効きます。

- JavaScriptは同じ配信元のみ。インラインスクリプト・HTMLイベント属性・evalを許可しません。
- 外部API通信は初期状態で禁止。同じ配信元のアプリ資産読込は許可。
- 同期する版では、ビルド時に指定したSupabase HTTPS originを1件だけ許可。他プロジェクトやワイルドカードは許可しません。
- 外部フォーム送信、object、アプリ内の外部フレーム、baseタグによるURL基点変更を禁止。
- フォントは同じ配信元、画像は同じ配信元とdata URLに限定。
- Service Workerは同じ配信元。オフライン資産もローカル配信します。
- 数式・グラフに必要なstyle属性は許可。対応ブラウザではstyle要素は同じ配信元のCSSに限定します。スクリプトのunsafe-inlineは本番で許可しません。
- 開発サーバーだけはReact Refresh/HMR用にインライン初期化とWebSocketを許可します。公開用distへこの緩和は入りません。
- 外部リンクを手動で開く際のRefererを送らない設定を追加。

設定はsrc/security.tsとvite.config.tsに集約。同期時は保存済みURLもSDK初期化前に承認済originと再照合します。以前の版で保存した他の接続先が自動的に許可されることはありません。

## できないこと・残るリスク

meta CSPではframe-ancestorsが効きません。別サイトからアプリ自体をiframeに埋め込むことを拒否するには、配信元のHTTPヘッダーを設定する必要があります。GitHub Pages向けmetaに無効なヘッダー指示を書いて対策済みとすることはしません。

CSPはすべての情報漏えい経路を封鎖するものではありません。同じoriginへの通信・自己配信のスクリプト・利用者がクリックする外部リンクは別です。配信元やGitHubアカウントが乗っ取られた場合、不正な更新は防げません。二要素認証・権限管理・更新確認が必要です。

GitHub Pagesの同じユーザードメインに別サイトを置く場合、ブラウザ上は同じoriginです。信頼できない別アプリを同じ配信元で運用しないでください。

アプリ独自のロック、JSONバックアップ暗号化、クラウドのE2E暗号化は今回の追加対象ではありません。端末ロックと本人だけが開けるバックアップ保管を併用してください。Supabase実サービスの認証・RLSは引き続き未検証です。

## 同期する版のビルド

同梱の標準distはローカル保存専用です。VITE_SUPABASE_ORIGINを空のまま使えます。

同期を使う場合、.env.exampleを参考に自分のPCで.env.localを作成し、公開してよいProject URLのみ設定します。

```text
VITE_SUPABASE_ORIGIN=https://your-project-id.supabase.co
```

設定後にnpm run build。アプリの設定画面に同じProject URLと公開用キーを設定します。パスワード・secretキー・service_roleキーを環境変数へ入れないでください。

GitHub Actionsの場合はリポジトリSettings → Secrets and variables → Actions → VariablesでSTUDY_SUPABASE_ORIGINを登録。公開済みURLは秘密ではありません。値を変えたら再ビルド・再公開します。未設定なら外部API通信を許可しない版になります。
